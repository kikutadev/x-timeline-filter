# X Timeline Filter

X（旧Twitter）のホームタイムラインに表示する投稿者を、端末内の許可リストで制限するManifest V3のChrome拡張機能です。

- 対象は `/home` の「おすすめ」「フォロー中」。プロフィールや検索、投稿詳細は変更しません。
- 再投稿は元の著者、引用投稿は外側の投稿者で判定します。判定できない投稿は、フィルターON時には非表示にします。
- 無限スクロール、SPA画面遷移、投稿セルの再利用に追従します。
- ポップアップでグループ・アカウントの追加と切り替え、フィルターのON/OFFができます。配色はOSのライト/ダーク設定に自動追従します。
- 設定はChromeの `chrome.storage.local` に保存します。初期状態はOFFです。
- Xへの独自API通信やCookieの取得、閲覧データの外部送信はしません。

## 読み込み制御

- Xのホームフィードは投稿セルを絶対配置し、要素の高さを使って仮想スクロールを管理するため、非表示セルの高さを0にせず24pxだけ残します。許可外の投稿本文は見えません。
- ホームでフィルターONの場合、描画された投稿IDを重複なく数え、60件ごとに下方向のスクロールを停止します。「さらに投稿を探す」を押すと次の60件まで再開します。件数は通信件数ではありません。
- フィルターOFF、グループ変更、ホーム以外への遷移では停止状態を解除します。X側ですでに開始した読み込みまでは中断できません。

## インストール

[Releases](https://github.com/kikutadev/x-timeline-filter/releases) のChrome向けZIPをダウンロードし、解凍したフォルダーをChromeの `chrome://extensions/` から「パッケージ化されていない拡張機能を読み込む」で選択してください。

Xtendでは、対応するバージョンのアプリにGitHubリポジトリURLを入力して導入できます。

## 使い方

1. 拡張機能のアイコンを開き、表示したい `@username` を登録します。改行やカンマで複数指定できます。
2. フィルターをONにします。グループ変更は表示中のタイムラインにも反映されます。
3. Xリストの詳細から「メンバー」を開いて閲覧・スクロールすると、画面に描画されたメンバーがローカルに蓄積されます。設定画面で「リストをグループに取り込む」を押すと、リスト名で専用グループを作成して表示対象に切り替えます。同じリストを再取り込みした場合は同じグループに未登録分を追加します。名称を取得できない場合は「Xリスト + ID」を使用します。ChromeとXtendで同じ手順です。自動スクロール・未表示メンバーの全件同期は行いません。

## 開発・テスト

Node.jsとpnpmが必要です。

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
pnpm zip
pnpm test:e2e
```

`test:e2e` はPlaywrightのChromiumを使用します。初回は `pnpm exec playwright install chromium` を実行してください。

XのDOM変更で判定が壊れる場合があります。非表示処理の絶対的な検知回避は保証しません。

## 配布物とライセンス

`release/` に配布用ZIPとSHA-256検証値があります。アイコンの原本は `assets/icon.svg`、Chrome用PNGは `public/icon/` に配置しています。

## 共通UIテーマ

ポップアップでは `src/styles/tokens.css` のshadcn/ui形式のsemantic CSS variablesを使います。テーマ正本はXtend親リポジトリの `shared/extension-ui/tokens.css`。FF Analyzerと同じ青色・ライト／ダーク・フォーカス・角丸を共有し、単独リポジトリのビルドのため同期後CSSをコミットしています。
